# PC Deck — guide d'installation

PC Deck transforme ta tablette (ou ton téléphone) en télécommande pour ton PC : boutons pour
lancer tes programmes et régler le son, températures et consommation en direct.

**Il te faut :** un PC sous Windows 10 ou 11, une tablette Android (ou un iPhone/iPad), et les
deux sur **le même Wi-Fi** (celui de ta box, pas le Wi-Fi « invité »).

---

## 1. Installer sur le PC (5 minutes)

1. Télécharge **PCDeck-Setup-…exe** (le lien que je t'ai envoyé) et ouvre-le.
2. Windows affiche peut-être **« Windows a protégé votre PC »** : clique sur
   **Informations complémentaires**, puis sur **Exécuter quand même**. C'est normal pour un
   petit logiciel fait maison.
   - Si Windows dit **« Une stratégie de contrôle d'application a bloqué ce fichier »**,
     arrête-toi et préviens-moi : ton PC a une protection renforcée, je t'expliquerai.
3. Windows demande **« Voulez-vous autoriser… ? »** : clique sur **Oui**.
4. Clique sur **Suivant**, puis **Installer**.
5. Si une question parle d'un réseau **« Public »** : réponds **Oui** si tu es chez toi
   (Non si tu es sur un Wi-Fi de café, de gare ou d'hôtel).
6. Clique sur **Terminer**. Une petite icône PC Deck apparaît près de l'horloge (en bas à
   droite ; parfois cachée sous la petite flèche **^**), et une page s'ouvre pour connecter
   ta tablette.

## 2. Connecter la tablette Android (5 minutes)

Sur le PC, la page **« Connecter un appareil »** est ouverte (sinon : clic droit sur l'icône
PC Deck → **Connecter une tablette ou un téléphone**). Onglet **Tablette Android** :

1. **Installer l'appli** : avec l'appareil photo de la tablette, scanne le **QR code n°1** et
   touche le lien. Le fichier **PC-Deck.apk** se télécharge : ouvre-le.
   - Android dit que l'installation depuis cette source est bloquée : touche **Paramètres**,
     active **Autoriser cette source**, puis reviens en arrière.
   - Si **Play Protect** dit « appli non reconnue » : **Plus de détails** → **Installer quand même**.
2. **Se connecter** : ouvre l'appli **PC Deck**. Elle trouve ton PC toute seule ; tape le
   **code à 6 chiffres** affiché sur la page du PC. (Ou scanne le **QR code n°2** et touche
   **Connecter**.)

Le code ne sert qu'une fois et change toutes les 5 minutes : c'est normal.

### iPhone ou iPad
Onglet **iPhone ou iPad** : scanne le QR code avec l'appareil photo, touche le lien. Dans
Safari, touche **Partager** puis **« Sur l'écran d'accueil »**. PC Deck s'ouvrira comme une appli.

## 3. Personnaliser

Clic droit sur l'icône PC Deck → **Paramètres** : ajouter, modifier, déplacer ou supprimer
des boutons (nom, icône, couleur, action), choisir le thème clair ou sombre, les infos
affichées… Clique sur **Enregistrer** : la tablette change tout de suite.

## 4. Mises à jour

- **PC** : une notification annonce la nouvelle version. Clic droit sur l'icône PC Deck →
  **Installer la mise à jour**, puis **Oui**. Tes réglages sont gardés.
- **Tablette** : après la mise à jour du PC, un bandeau propose la nouvelle version de
  l'appli → **Installer**. La première fois, Android demande d'autoriser PC Deck à installer
  des applis : **Paramètres** → **Autoriser cette source**.

## 5. Si ça ne marche pas

| Problème | Solution |
|---|---|
| La tablette ne trouve pas le PC | Le PC est allumé, avec l'icône PC Deck près de l'horloge ? Les deux sont sur le **même Wi-Fi** (pas « invité ») ? Clic droit sur l'icône : si tu vois « Réseau « Public » », clique dessus. |
| « Code incorrect » ou « expiré » | Sur le PC : **Connecter un appareil** → **Nouveau code**. |
| Températures vides (« — ») | Attends une minute après le démarrage du PC ; sinon redémarre le PC. Certaines puces graphiques intégrées n'ont pas de température : c'est normal. |
| L'icône PC Deck a disparu | Menu Démarrer → **PC Deck**. |
| Désinstaller | Paramètres Windows → Applications → **PC Deck** → Désinstaller. Sur la tablette : appui long sur l'appli → Désinstaller. |
